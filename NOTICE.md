## Why this file exists

GPLv3 section 14 states that when a program specifies a numbered version of the GNU GPL *without*
granting "or any later version", only that numbered version applies. A bare copy of the GPLv3 text
therefore amounts to **GPL-3.0-only**.

This notice supplies the explicit upgrade grant. It is reproduced machine-readably in every source
file as `SPDX-License-Identifier: GPL-3.0-or-later`, so the grant still travels with any single file
copied out of this repository.

`LICENSE` is deliberately left as the verbatim, unmodified GPLv3 text: GitHub's licence detector
matches on that text, and prepending anything to it makes GitHub report the project as "Other".
